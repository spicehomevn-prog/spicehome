SpiceHome's icon set — the exact Lucide glyphs the product uses, embedded as a React-only component (no npm dependency).

```jsx
<Icon name="map-pin" size={15} className="accent" />
```

Color it by setting `color` on the icon or a parent (it uses `currentColor`). Common names: `bed-double`, `users`, `images`, `map-pin`, `phone`, `mail`, `message-circle`, `clock`, `lightbulb`, `external-link`, `chevron-down`, `menu`, `x`. Default size 20px, stroke-width 2 — match Lucide.
