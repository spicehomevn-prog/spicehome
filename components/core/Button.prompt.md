The house call-to-action — square corners, uppercase Inter, wide letter-spacing. Use for every booking/navigation action.

```jsx
<Button variant="primary" href="https://airbnb.com/...">Book on Airbnb</Button>
<Button variant="outline">View All Rooms</Button>
```

Variants: `primary` (solid terracotta), `outline` (graphite hairline → inverts to ink), `accentOutline` (terracotta outline → fills), `onDark` / `ghostOnDark` for use over the ink/photo bands. Sizes `sm | md | lg`. Pass `href` to render an anchor. Never round the corners.
